## 关于我

我关注 AI 辅助开发、后端系统、网络工具链和个人效率工具，喜欢把高频工程流程做成可复用的小工具。

- 常用技术栈覆盖 Java、Python、Go、JavaScript、TypeScript、Rust。
- 关注 coding agents、developer tooling、proxy/network stacks、knowledge workflows。
- 通过 PR、Issue 和代码变更参与开源项目。
